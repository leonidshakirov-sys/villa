# Фотографии дома

Положите сюда реальные снимки объекта. Чужие и сгенерированные фотографии использовать нельзя.

Рекомендуемый формат: **WebP**. Дополнительно можно положить рядом AVIF с тем же именем.

Имена файлов уже прописаны в `src/config/property.ts`:

- `house-exterior-01.webp` — главное фото (hero, финальный экран, Open Graph)
- `house-exterior-02.webp`
- `house-facade-01.webp`
- `house-facade-02.webp`
- `house-yard-01.webp`
- `house-land-01.webp`
- `house-veranda-01.webp`
- `house-interior-01.webp`
- `house-interior-02.webp`
- `house-room-01.webp`
- `house-stairs-01.webp`
- `house-floor-01.webp`
- `house-garage-01.webp`
- `house-sauna-01.webp`
- `house-surroundings-01.webp`

Пока файла нет, на сайте показывается нейтральная заглушка с подсказкой имени.

После загрузки фотографий пересоберите сайт: `npm run build`.
